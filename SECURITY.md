# Security Policy / 安全策略

## 受支持的版本 / Supported Versions

| 版本 / Version | 是否支持安全更新 / Security Updates |
|---|---|
| master (当前稳定版) / Current stable | ✅ Yes |
| feat/chattts (开发分支) / Development | ✅ Yes |
| 旧版本 / Older versions | ❌ No |

## 报告漏洞 / Reporting a Vulnerability

我们非常重视安全。如发现安全漏洞，请按以下方式报告：

We take security seriously. If you discover a security vulnerability, please report it via:

1. **GitHub Security Advisory**（推荐）/ Recommended: [Report via GitHub](https://github.com/HoweBai/voice-novel/security/advisories/new)
2. **电子邮件** / Email: howebai@example.com

**请勿在公开 Issue 或讨论区披露漏洞细节**，以便我们有时间修复后再公开。
Please do not disclose the vulnerability in public Issues or discussions until we have had time to fix it.

## 处理流程 / Response Process

- 我们会在 **48 小时内** 确认收到报告
- 修复期间会保持与报告者的沟通
- 漏洞修复后会在 Release Notes 中致谢（可选择匿名）

## 依赖安全 / Dependency Security

本项目使用 Dependabot 监控依赖安全更新。发现高危漏洞时会自动创建修复 PR。

This project uses Dependabot to monitor dependency security updates. High-severity vulnerabilities will automatically trigger fix PRs.
